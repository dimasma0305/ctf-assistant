# Picking a visual that actually makes the joke

Start from the requested action/expression and the audience's shared references.
A named template is a useful constraint; a catalog's popularity order is not.

## Search outside the usual formats

- For a named reference, search its exact name and spelling variants, then the
  scene/action plus `template`, `reaction`, `gif`, or `blank`. Character names
  can have aliases: `Bakushin`, `Bakushin O`, `Sakura Bakushin O`, `バクシン`.
  A nonsexual excited/running Bakushin reaction can fit reckless enthusiasm or
  rushing ahead before understanding instructions; inspect the actual clip.
- For an unnamed reference, search the visible joke, not the whole chat:
  `cartoon exaggerated applause reaction`, `awkward side eye puppet template`,
  `anime smug then shocked reaction`, `cat panic computer meme`.
- Try a different source or an alias when the first catalog has no match.
  Public template pages, Tenor/Giphy scene pages, original public creator posts,
  and contextual meme indexes can help locate the original asset. An index
  explains a reference; it is not proof that every suggested image fits it.
- Acquire the main asset linked from the inspected page. In particular, a GIF
  page can include unrelated recommended clips: do not choose the first media
  URL from the entire page or treat tags as a description of pixels.
- Keep a small private shortlist with source, visible action, and why it fits.
  When the user specifically asks for a different format, inspect alternatives
  outside the family just used. Pick for visual fit, caption readability, and
  whether this community already overused it; novelty alone does not make it funny.
  Stop searching once there is a good fit. No forced rotation or fixed quota.

Possible directions, **not a routing table or a complete library**:

| Comic mechanism | Visual leads worth checking | Caption mistake to avoid |
| --- | --- | --- |
| Awkward recognition / keeping quiet | Monkey Puppet side-eye, side-eye dog, a reaction screenshot | Explaining what the stare means |
| Overconfidence meets reality | Smug-to-shocked anime panels, Gru's Plan, shocked Pikachu | An unrelated second panel |
| Sycophancy / exaggerated praise | Smithers praising Burns, a bowing or applauding reaction | Calling every flattery joke a two-option choice |
| Rushing in without thinking | Nonsexual Bakushin sprint/cheer reactions, running cartoon loops | Captioning a static happy face as if it shows running |
| Different standards for the same thing | Squidward's contrasting reactions, corporate approval panels | Two captions that don't actually contradict |
| Deadpan repetition | Squidward's "How original" scene, tired cashier reaction | Repeating an overused template to complain about overuse |
| Escalating chaos | Community pizza/fire scene, Tom panic, frantic reaction GIF | Writing a paragraph over every frame |
| Denial / suspicious innocence | Side-eye cat, hiding puppet, sweating character | Inventing misconduct by a real member |

## Make the caption sound like this chat

Use the shortest setup that makes the visual land. For example, an awkward
reaction to a teammate calling an unexpectedly easy task "warmup" may need only
the detail that you have been stuck for four hours. The expression supplies the
rest. Do not add "me feeling embarrassed" to explain the expression.

For an office-flattery joke, a concrete reversal is more useful than the generic
word "atasan": an idea gets rejected, then the boss repeats it and everyone
applauds. Keep fictional office roles fictional; do not attach that conduct to
a Discord member without their actual words/context.

Read the latest speaker and request again before delivery. Someone else's new
request for a photo is not another reply in the previous person's meme debate.
A person proposing a relevant template should not receive only a teasing
one-liner when the active task is to revise the image.

## Inspect motion and layout

- Check the actual image. For GIFs inspect frames across the clip and its loop.
  Preserve timing and credit marks; a thumbnail cannot establish the whole gag.
- Prefer a caption band for reaction images with no clean negative space.
  Object labels work when the object/role assignment is immediately clear.
- At Discord phone size, the punchline should be readable without zooming. If
  the minimum readable font doesn't fit, shorten the setup or choose another
  layout. Do not squeeze in a second explanation.
- Keep acquisition failures distinct from taste: if a particular asset cannot
  be obtained, say so briefly and offer a clearly named alternative. Do not
  claim to have found or edited a reference that was never inspected.
