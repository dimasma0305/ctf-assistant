# Shared agent-session upgrade — 2026-10-30

This change reproduces documented public agent-session behavior without
claiming to reverse engineer ChatGPT's private implementation. The relevant
public contracts are:

- [Agent sessions](https://developers.openai.com/api/docs/guides/agents-api/sessions):
  an idle message starts a turn and a message during a turn steers it.
- [Steering](https://developers.openai.com/api/docs/guides/steering): pending
  steering must be recorded rather than assumed to survive one connection.
- [Dots messaging](https://learn.chatgpt.com/docs/dots/channels): one agent can
  participate with multiple people while channel visibility remains scoped.
- [Dots tasks and memory](https://learn.chatgpt.com/docs/dots/tasks-and-memory):
  responsibilities can be inspected, reprioritized, and continued.
- [Dots controls](https://learn.chatgpt.com/docs/dots/controls): delegated work
  needs separate inspection and stop controls.

## Implemented contract

- GPT-6.1 Sol remains the general conversational manager. A small semantic
  router chooses GPT-5.6 Sol for an actual security, CTF, reproduction, or
  public-profile/technical OSINT turn. The selected manager still chooses its
  own tools; the router does not dispatch actions from keywords.
- The manager chooses GPT-5.6 Sol workers for security/CTF/technical OSINT and
  GPT-6.1 Sol workers for general agent work. Daybreak remains an allowlisted
  hard-security option.
- Production workers have no application count quota for model calls,
  searches, guarded reads, downloads, vision reads, or permission-checked
  same-channel Discord reads. Provider and account limits plus isolation,
  target permission, file-size, process, memory, and network boundaries remain.
- A channel can hold four independent pending/running responsibilities by
  default. Job listings contain objective, model, state, statistics, sources,
  steering state, files, and terminal results.
- Any participant in the originating channel/thread may list, inspect, or
  steer its jobs. Only the owner or allowlisted creator may cancel. An active
  direction is persisted and injected at the next inference boundary; a
  terminal follow-up creates a continuation carrying the prior result and
  sources.
- Workers can ask the permission-checked broker for current same-channel text,
  embeds, image pixels, and bounded prior bot attachments. They cannot access
  other channels, Discord credentials, or DMs.
- A transient model-stream failure resumes the same disposable Codex session
  up to three consecutive recovery attempts. Production jobs have no default
  application wall-clock deadline and remain explicitly cancellable.

## Forward benchmarks

All live cases use synthetic Discord IDs and make no Discord or database
writes.

| Gate | Result |
| --- | --- |
| GPT-6.1 Sol provider smoke | 5/5: text, JSON, image input, tool call, native search; six real OAuth requests |
| GPT-5.6 Sol isolated worker smoke | Pass: irai skill read, successful Python receipt, correct medians and 2.2 ratio; six model calls |
| Injected stream interruption | Pass: first provider stream deliberately closed, same session recovered, verified answer completed; five provider requests |
| Semantic manager/worker routing before tuning | 10/11, with one actual challenge taking an unnecessary manager read step |
| Semantic manager/worker routing after tuning | 11/11; zero false Codex calls on casual, conceptual, and arithmetic cases |
| Long unbounded research probe before recovery | Reached 43 model calls, 26 searches, 27 reads; exposed a real stream interruption instead of an old count cap |
| Long probe after recovery | Reached 49 calls, 33 searches, 27 reads and entered same-session recovery; the benchmark's old 900-second outer timeout, not production, stopped it. The harness now defaults to no deadline. |

The 11 routing cases cover casual chat, a conceptual CTF question, a binary
puzzle without the word CTF, an explicit WordPress challenge, a simple public
lookup, multi-repository CTF-platform research, two profile-OSINT forms,
continuing shallow technical research, a general multi-country report, and a
small calculation. Each delegated case also checks the worker model selection.

These are focused regressions, not proof of universal intelligence or an
optimal prompt for every future conversation. Keep the failed pre-fix traces
as evidence of what changed, and use a fresh holdout corpus before claiming
further prompt improvements.
